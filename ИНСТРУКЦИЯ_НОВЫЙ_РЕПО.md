# Новый репозиторий: сайт + бот + Stars (всё онлайн)

## 1. Репозиторий и файлы
1. github.com → New repository, имя любое (например `qcup`), **Public** (для бесплатных Pages).
2. Add file → Upload files. GitHub принимает до 100 файлов за раз, поэтому архив из двух частей: распакуйте обе, загрузите сначала часть 1, потом часть 2
   (перетаскивайте папки и файлы), Commit changes после каждой.
   Скрытая папка `.github`: если не перетащилась, Add file → Create new file, имя `.github/workflows/deploy-worker.yml`, вставить текст из архива (так же `deploy-pages.yml`).
3. В корне репозитория должны лежать `frontend`, `backend`, `worker`, `.github`, без лишней папки `QcUp` сверху.

## 2. Сайт
Settings → Pages → Source: **GitHub Actions**. Вкладка Actions → «Deploy QcUp to GitHub Pages» станет зелёной, сайт откроется на `https://ваш-логин.github.io/имя-репозитория/`.

## 3. Бот и Stars
Откройте `worker/README.md` и пройдите его: регистрация в Cloudflare, 4 секрета в GitHub, один запуск в Actions.

## 4. Связать сайт с сервером
В `frontend/public/config.json` впишите адрес сервера платежей из отчёта запуска (инструкция в worker/README.md). Commit.
