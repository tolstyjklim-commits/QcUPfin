Админ-панель пополнений

Здесь вы задаёте кошельки для приёма платежей, проверяете их и получаете файл config.json, который кладётся рядом с сайтом.

Важно. Эта страница открыта для всех и ничего не меняет на сайте сама: она только готовит файл. Настройки вступают в силу, когда вы загрузите config.json в репозиторий (папка frontend/public). Не вводите сюда приватные ключи и сид-фразы. Нужны только публичные адреса кошельков.

1. Кошельки для приёма не проверен

Платежи в TON и в USDT (сеть TON) поступают на один и тот же адрес.

USDT в сети TRON (TRC20) не проверен

2. Какие способы показывать игрокам

TONОпознаётся по уникальному комментарию в переводе
USDT (сеть TON)По адресу отправителя, точной уникальной сумме и времени перевода
USDT (сеть TRON, TRC20)По адресу отправителя, точной уникальной сумме и времени перевода
Telegram Stars ⭐Оплата прямо в Telegram, 1 Star = 1 ⭐. Работает только с сервером (VPS): без него способ скрыт у игроков

3. Лимиты и время

3.5. Сервер платежей (Cloudflare Worker)

Адрес вашего Worker, например https://qcup-pay.ваш-аккаунт.workers.dev. Когда он указан, пополнение Stars идёт по-настоящему через бота, а проверка платежей переходит на сервер. Пустое поле: платежи проверяет браузер, Stars работают только в тестовом режиме.

4. Ключи и запасной курс (необязательно)

Ключи попадут в публичный config.json и будут видны всем. Заводите отдельные ключи только для этого сайта.

Запасной курс используется, только если не удалось получить рыночный.

5. Готовый config.json

{}
  1. Скачайте config.json и положите в папку frontend/public проекта (рядом с admin.html).
  2. Загрузите изменения в репозиторий (push). GitHub Pages пересоберёт сайт за пару минут.
  3. Откройте сайт, нажмите «Пополнить» и проверьте, что видны нужные способы.

«Применить на этом устройстве» сохраняет настройки только в этом браузере, чтобы проверить окно пополнения до загрузки файла. Другим игрокам они не видны.

6. Доступ к демо-балансу выключен

Страница demo.html всегда открывается на вашем компьютере при локальном запуске. На опубликованном сайте она работает только по паролю. Игроки пароля не знают, поэтому демо для них недоступно.

В config.json попадает только необратимый хэш пароля. Придумайте длинный пароль: слабые пароли по хэшу можно подобрать. Если демо вам не нужно, лучше вообще удалить demo.html.

7. Журнал платежей (этого браузера)

Показывает события пополнения, которые обработал этот браузер: создание заявки, зачисление, отклонённые платежи, ошибки опроса. Журнал открывается там же, где открыта игра (тот же адрес сайта). Серверный журнал лежит в файле logs/payments.jsonl на VPS.

Нажмите «Обновить».

Как платёж привязывается к игроку

  • TON. В заявке игрока есть случайный комментарий (memo). Платёж с таким комментарием зачисляется именно этой заявке.
  • USDT (TON и TRON). К переводам USDT нельзя надёжно прикрепить комментарий, поэтому игрок указывает адрес своего кошелька, к сумме добавляется уникальная «копейка» (до 0,01 USDT), и засчитывается только перевод с этого адреса, на точную сумму и после создания заявки.
  • Telegram Stars. Игрок платит счётом внутри Telegram, бот сервера подтверждает оплату и зачисляет ⭐ один раз (по номеру платежа Telegram). Нужен сервер и токен бота в его .env; лимиты на сервере задаются MIN_DEPOSIT_STARS и MAX_DEPOSIT_STARS.
  • Честное ограничение. Платёж принимается, только если он сделан внутри окна заявки (не раньше создания и не позже истечения), и один платёж зачисляется один раз. Пока сайт работает без своего сервера, баланс хранится в браузере игрока, а проверка платежа делается на его стороне. Для вывода денег и защиты от подделки нужен серверный режим (см. DEPLOY.md).
