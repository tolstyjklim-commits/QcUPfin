# Полный архив для тестов (с админкой)

В этом архиве всё лежит на своих местах, ничего переносить не нужно. Админка здесь входит в сайт специально, чтобы вам было проще тестировать.

- Админ-панель выводов и игроков: `frontend/public/panel.html`. После выкладки на GitHub Pages она открывается по адресу `https://<логин>.github.io/<репозиторий>/panel.html`. Дополнительно настраивать `ADMIN_ORIGIN` не нужно: адрес панели совпадает с адресом сайта игры, который Worker уже разрешает.
- Старая панель кошельков: `frontend/public/admin.html`.
- Копии этих файлов лежат и в корне проекта.

**Важно.** Пока админка лежит на сайте, её адрес открывается у всех, кто его знает. Без `ADMIN_KEY` панель ничего не показывает, но для настоящего запуска уберите `panel.html` и `admin.html` из `frontend/public` и храните их отдельно (см. `README-admin-panel.md`, архив `QcUp-admin.zip`).

Как войти в панель: откройте адрес панели, вставьте адрес Worker и `ADMIN_KEY`. Подробности в `README-admin-panel.md`.
